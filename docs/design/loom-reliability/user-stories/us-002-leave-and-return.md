# US-002 — Leave and return deliberately

**Actor / context:** A developer using one conversation for changing priorities, with other sessions potentially working independently.

**Trigger:** An exploratory idea is no longer wanted, or ongoing A must wait while B takes priority.

**Goal:** Stop pursuing the selected idea or work, do something else, and return to retained work when desired.

**Observable success:** No fake acceptance is required to leave an interview. Pause, cancellation and conversational attention remain distinct. Returning identifies exact work, retained progress, current obligations and running/unknown operations. Cancelling B neither completes B nor cancels A. Existing answers are retrievable and usable without answering again or coordinating transport.
