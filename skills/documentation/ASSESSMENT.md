# documentation Reviewer Assessment

Reviewer-only domain contract. It does not create Loom authority, product meaning, or proof.

## Review criteria

- Current-reality docs match observed implementation without laundering implementation into normative authority.
- Changed facts are updated and unaffected docs are not rewritten ceremonially.
- System maps remain concise/navigational while preserving load-bearing components, flows, state, operations, and public seams.
- User-facing instructions match real commands/behavior and omit unsupported claims.
- Authority conflicts are routed instead of documented as accepted reality.
- Discovery/indexing checks prove the changed docs are findable.

## Review depth

Scale review depth with consequence, uncertainty, boundary count, and blast radius.
