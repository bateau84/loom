# agent-file-authoring Quality Assurance

Critic-only adversarial contract. Assume competent production and Reviewer conformance have already occurred; attack residual false confidence without creating new authority.

## QA criteria

- Ask what wrong action a capable model now feels explicitly authorized or obligated to take because of the edited prompt.
- Look for correlated prompt/control-plane assumptions that deterministic validation would not catch.
- Attack permission broadening hidden behind apparently narrower prose, and prose obligations the permission layer cannot actually satisfy.
- Look for non-terminating correction loops, coordinator bias of independent gates, and local-green-as-product-complete reasoning.
- Test whether stale wording elsewhere can still teach the superseded behavior.
- Treat validator/eval changes that merely make the new prompt green as suspect until they still discriminate the original failure mode.

## QA depth

Increase QA depth where a shared wrong assumption could survive both competent production and normal review.
