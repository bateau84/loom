## Reproduction

Run the commands in [README.md](README.md) from this branch. They install the exact
packed candidate in a disposable directory, run full Loom core/native/Python
regressions and start a real installed OpenCode 2.1.4 host. The new suite also
launches independent Bun OS processes against the actual shared SQLite
implementation. Full results are generated by CI at the PR commit; this file
is a *test contract*, not a fabricated successful test report.

## Results and limits

The runner writes all 12 requested requirements with **PASS**, **FAIL**, or
**UNPROVEN**, and separately records observed installed-host provider routes,
native execute before/after counts, installed quota state initialization,
restarts, real independent-process quota observations and failing negative
controls. An assertion failure exits nonzero, sets report status FAIL and
must block readiness. Only an actually executed, green CI run provides
passing installed-host evidence.

Positive native class selection and reasoning, same-model/next-provider route
selection, selection after shared exhaustion, committed-route pre-dispatch
rejection and native account/stream lease cannot currently be marked PASS:
the local fixtures have **no independently verified included billing**.
Native adapter tests use **test-only attestations** and are labelled as
mocked. Quota child-process tests use synthetic reported failures and
synthetic completed probe success and are labelled state-level.

OpenCode Go subscription eligibility, real-provider quota accounting, matched
2.1.4 SDK qualification, managed post-tool failure affinity and live automatic
provider switching remain **UNPROVEN**. In-flight switching is not a criterion
of this PR and must not be silently added. Do not merge this draft based only
on passing synthetic tests.
